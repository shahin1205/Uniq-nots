Method Reference:
-----------------
-> Java 8 introduced Method Reference as a shorthand notation of a 
	lambda expression to call a method directly instead of 
		provide implementation.
-> It is used to refer to a method of a class or an object without 
	executing it.
-> Method references are just a alter native for lambdas that
		directly refer the existing method or constructor.
		
1. Reference to a Static Method
	InterfaceName::methodName
	ClassName::methodName
	
2. Reference to a Instance Method
	objectReference::methodName
	
3. Reference to a Constructor
	ClassName::new

4. Arbitrary-Object Method Reference
	ClassName::instanceMethodName
	-> only working with streams or collections

Method References are Commonly Used:
------------------------------------
| Lambda Expression                    | Method Reference Equivalent   |
| ------------------------------------ | ----------------------------- |
|  n -> Math.sqrt(n)                   |  Math::sqrt                   |
|  str -> str.toUpperCase()            |  String::toUpperCase          |
|  () -> new Person()                  |  Person::new                  |
|  (a, b) -> a.compareToIgnoreCase(b)  |  String::compareToIgnoreCase  |
------------------------------------------------------------------------
1. Advantages of Method References:
-----------------------------------
-> Shorter and cleaner code (avoids repeated lambda expressions).
-> Improves readability.
-> It's use functional programming style.

OPTIONAL CLASS:
---------------
-> Optional<T> is a container object introduced in Java 8 in the java.util package.
-> It may or may not contain a non-null value of type T.
-> It’s mainly used to avoid NullPointerException and make 
	null-handling more explicit.
-> Instead of returning null from a method,
	you return Optional.empty() or Optional.of(value).
-> Works well with streams.

Optional["hello"]

Static Methods in Optional
--------------------------
1. Optional.empty()
> Returns an empty Optional.
example:
--------
Optional<String> op = Optional.empty();

2. Optional.of(value)

> Returns an Optional with the given non-null value. 
> Throws NullPointerException if value is null.
example :
---------
Optional<String> op = Optional.of("Hello");
op.get() // return given value

Optional<String> op = Optional.of(null);
op.get() // throws NullPointerException

3. Optional.ofNullable(value)

> Returns an Optional with the given value, or Optional.empty if value is null. 

Optional<String> op = Optional.ofNullable(name); 
op.get() // return given value

Optional<String> op = Optional.ofNullable(null); 
op.get() // return Optional.empty

Stream API
----------
-> The Stream API was introduced in Java 8.
-> inside the java.util.stream package.
-> It is used to process collections of data 
	(like List, Set, Map, arrays, or I/O data) in a 
		declarative and functional style.
-> Instead of writing loops manually, 
	the Stream API helpful to use pipeline operations.
	
About Streams:
--------------
1. Not a Data Structure:
-> Stream doesn’t store data. It works on top of collections or arrays.
-> here list.stream() creates a stream from a list.

2. Functional Style:
-> You can write concise code using lambda expressions.

3. Pipeline of Operations:
-> Stream operations are chained into a pipeline.

4. Lazy Evaluation:
-> Intermediate operations are will not be executed until terminal operation
	executes.
	
5. Can Be Sequential or Parallel:
-> Sequential (default): list.stream()
-> Parallel (multi-threaded): list.parallelStream()

1. Intermediate Operations (return another stream):
---------------------------------------------------
-> Methods are chained together.
-> Intermediate operations transform a stream into another stream.
-> It enables the concept of filtering where one method filters data 
	and passes it to another method after processing.
