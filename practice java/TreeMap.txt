TreeMap (class)
---------------
TreeMap is a part of java.util package and implements the NavigableMap interface,
which extends SortedMap.
It stores key–value pairs in sorted (ascending) order of keys by default 
	(based on natural ordering or a custom Comparator you provide).

Keys are always sorted (ascending by default).
underlying Red-Black Tree (a self-balancing binary search tree) data structure.
null keys not allowed.
Not Thread safe.

Node structure:
---------------
static final class Entry<K,V> implements Map.Entry<K,V> 
{
    K key;
    V value;
    Entry<K,V> left;
    Entry<K,V> right;
    Entry<K,V> parent;
    boolean color; // RED or BLACK
}

TreeMap Works Internally

Insertion:
1. If the map is empty → create a root node (colored BLACK).
2. Else, it compares the new key:
	if key < current.key → go left
	
	if key > current.key → go right

	if key == current.key → replace value.
3. Insert the node as a red node (by rule).
4. Rebalance the tree to maintain Red-Black Tree properties.

Balancing Rules:
----------------
Every node is either red or black.
The root is always black.
All leaves (nulls) are considered black.
Red nodes cannot have red children.
Every path from a node to its descendant leaves has the same number of black nodes.

1. Map Methods:
| Method                                | Description                    | Example                        |
| ------------------------------------- | ------------------------------ | ------------------------------ |
|  V put(K key, V value)                | Add or update a key-value pair |  map.put(1, "Apple");          |
|  V get(Object key)                    | Returns value for given key    |  map.get(1);                   |
|  boolean containsKey(Object key)      | Checks if key exists           |  map.containsKey(2);           |
|  boolean containsValue(Object value)  | Checks if value exists         |  map.containsValue("Banana");  |
|  V remove(Object key)                 | Removes entry by key           |  map.remove(3);                |
|  int size()                           | Returns number of entries      |  map.size();                   |
|  void clear()                         | Removes all mappings           |  map.clear();                  |
|  boolean isEmpty()                    | Returns true if map empty      |  map.isEmpty();                |
|  Set<K> keySet()                      | Returns all keys               |  map.keySet();                 |
|  Collection<V> values()               | Returns all values             |  map.values();                 |
|  Set<Map.Entry<K,V>> entrySet()       | Returns all entries            |  map.entrySet();               |

2. SortedMap Methods:
| Method                                      | Description                                            | Example               |
| ------------------------------------------- | ------------------------------------------------------ | --------------------- |
|  K firstKey()                               | Returns the   lowest key                               |  map.firstKey();      |
|  K lastKey()                                | Returns the   highest key                              |  map.lastKey();       |
|  SortedMap<K,V> headMap(K toKey)            | All keys   less than toKey                             |  map.headMap(50);     |
|  SortedMap<K,V> tailMap(K fromKey)          | All keys   greater than or equal to fromKey            |  map.tailMap(30);     |
|  SortedMap<K,V> subMap(K fromKey, K toKey)  | All keys in   range [fromKey, toKey)                   |  map.subMap(10, 50);  |
|  Comparator<? super K> comparator()         | Returns comparator used (or null for natural ordering) |  map.comparator();    |
