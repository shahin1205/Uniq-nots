Collection Factory Methods:
---------------------------
| Interface   | Methods                            | Description                           |
| ----------- | ---------------------------------- | ------------------------------------- |
|  List       |  List.of(E... elements)            | Immutable list creation.              |

|  Set        |  Set.of(E... elements)             | Immutable set creation.               |

|  Map        |  Map.of(K, V, K, V, ...)           | Immutable map creation.               |
|             |  Map.ofEntries(Map.Entry<K,V>...)  | Immutable map from entries.           |

|  Map.Entry  |  Map.entry(K key, V value)         | Creates an immutable key-value entry. |
